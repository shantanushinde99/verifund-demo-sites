# Demo sites

Two versions of a small bakery website used in the Proof-of-Done demo video, served by GitHub Pages.

- `bakery-v1/` is intentionally incomplete: the contact email has a typo (`helo@`), there is no contact form, and the "Meet the team" link is broken.
- `bakery-v2/` is the fixed version: correct email, a working contact form, and a team page.
